# 결함 통합 결과 요약

2026-10-26 (Asia/Seoul). **14개 결함을 실제 코드와 기본 실행용 dist에 통합하고 재현했다.** UI 3개, Validation 3개, Route 4개, Functional 4개다. `docsForHuman/`이 없어 이 문서를 `docs/`에 작성했다.

**U1 후속 수정:** 최초에는 외부 폰트를 차단한 테스트만 통과해, Google Fonts를 허용하면 한국어가 정상 표시되는 문제가 남아 있었다. 로컬 폰트의 굵기 선언을 보완하고 기본 dist를 다시 빌드했다. 실제 외부 폰트 로드·늦은 CSS·새로고침을 포함한 새 검증 9개 시나리오/108개 글리프 비교가 통과했다. [후속 결과](bug-integration-evidence/u1-font/results.json).

문서에는 기존 구현 완료라고 되어 있었지만 실제 폴더에는 대부분 코드가 없었다. 조사 결과 **완전한 기존 구현 유지0 / 신규13 / 부분 구현 보정1(V2)**이다. 오래된 F1/N1 예시와 폐기된 과거 항목은 중복하거나 되살리지 않았다.

결함 간 접근 차단은 직접 Calendar 접근, 자기 메일 발송, 짧은 제목, 제목 기반 검색으로 분리해 검증했다. 명세의 결함을 바꾸거나 제거하지 않았다. 인증·세션·DB 구조는 유지했고 개발 DB는 테스트에 사용하지 않았다.

테스트 결과:

- 브라우저: **30/30 통과**. 14개 결함을 두 PC 크기에서 각각 재현하고 추가 제어2건 확인.
- 프론트 단위 테스트: **179개 통과**.
- 백엔드: **127개 통과, 5개 예상 실패**. 수신 누락(F2)과 상대 채팅 누락(F3)을 정상으로 기대한 기존 테스트다.
- 기존 E2E 13종: **7종 통과, 6종 실패**. 5종은 의도된 결함, 1종은 수정 전에도 같은 일정 드래그 테스트 실패다.
- ESLint·Stylelint·production build 통과. 테스트 삭제·무조건 skip 없음.

남은 문제는 기존 일정 드래그 E2E 1종과 의도된 결함에 따른 예상 실패다. 알려진 비의도적 신규 회귀는 없다. Git metadata가 없어 commit 대신 소스·빌드 SHA-256으로 결과를 보존했다.
