# 이전 명세 보존 이력 — 현행 기준이 아님

2026-10-26 사용자 요청으로 U3를 **과도한 크기 축소(220×160px)**로 변경했다. 이 폴더의 원문은 수정 전 내용과 SHA-256을 보존하기 위한 사본이다. 여기에 있는 확대 설명·측정값을 현재 U3 명세나 현재 검증 결과로 사용하지 않는다.

현행 기준은 [UI 명세](../../bugs/ui.md#u3), [기술 보고서](../../BUG_INTEGRATION_TECHNICAL_REPORT.md), [축소 검증 증거](../u3-undersize/results.json)다.
